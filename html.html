Arquitetura Clinte servidor da WEB

As tecnlogias fundamentais que compoem a WEB são:

  • Arquitetura Cliente servidor
  • HTTP - Hyper Text Tranfer Protocol
  • HTML - Hyper Text Markup Language é uma linguagem de programação nota1
  • Naegador Cliente
  • Servidor Web

Ao longo dos anos a web evoluiu e nova tecnlogias foram incorporadas como CSS e JavaScript
